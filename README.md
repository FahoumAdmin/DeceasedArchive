# People PWA - מערכת חיפוש אנשים

אפליקציית PWA לחיפוש והצגת פרטי אנשים מתוך קובץ JSON מקומי.

המערכת בנויה בטכנולוגיות:

- HTML
- CSS
- JavaScript
- JSON
- Service Worker

ללא צורך בשרת Backend.
